# Elsevier

> Elsevier is a Dutch academic publishing company (a RELX business) whose Research Products APIs
> expose Scopus, ScienceDirect, SciVal, Embase, Engineering Village and COUNTER usage reporting
> over one host, https://api.elsevier.com. All access is by API key plus an institutional
> entitlement: the key identifies your application, and your institution's subscription decides
> what comes back.

Generated by API Evangelist on 2026-09-06 from Elsevier's own published contracts and
documentation. Elsevier does not publish an llms.txt of its own — /llms.txt returns 404 on
dev.elsevier.com, api.elsevier.com and www.elsevier.com. Note that dev.elsevier.com/robots.txt
Disallows GPTBot, ChatGPT-User and Google-Extended, and every api.elsevier.com response carries
a `tdm-reservation: 1` header.

## Base URL

- https://api.elsevier.com — every product, every operation

## Authentication

- `X-ELS-APIKey: <key>` on every request (register at https://dev.elsevier.com/apikey/manage)
- Entitlement is resolved from your institutional IP address. A valid key called from outside
  the subscribing network returns 401/403 even though the key is fine.
- `X-ELS-Authtoken` — from GET /authenticate?platform=SCOPUS, expires two hours after issue
- `X-ELS-Insttoken` — an Institutional Token for remote access, issued by Elsevier on request
- Elsevier also documents the key as an `apiKey` query parameter. Do not use it; it puts a
  credential in logs, history and referrers.
- Elsevier runs a real OAuth 2.0 / OpenID Connect authorization server at
  https://id.elsevier.com (discovery at /.well-known/openid-configuration and
  /.well-known/oauth-authorization-server, both HTTP 200 anonymously, probed 2026-09-06). It
  is the identity provider behind the developer-portal sign-in. NONE of its 35 advertised
  scopes governs a Research Products API operation, api.elsevier.com serves no
  oauth-protected-resource document (404), and no page on dev.elsevier.com names the server.
  Do not treat it as an authorization model for the content APIs.

## Limits

- [Default API key settings](https://dev.elsevier.com/api_key_settings.html) — per-API weekly
  quotas and per-second throttles. Quotas are per API, not per key: 20,000/week for Scopus
  Search, 5,000/week for Author Search, 50,000/week for ScienceDirect Article Retrieval.
- Quotas reset every seven days. Read `X-RateLimit-Limit`, `X-RateLimit-Remaining` and
  `X-RateLimit-Reset` (a Unix timestamp). When the weekly quota is exhausted the first two stop
  being returned and `X-ELS-Status: QUOTA_EXCEEDED` appears instead.
- Exhaustion and throttling both return HTTP 429. There is no `Retry-After`.
- Eight APIs are access-controlled and not enabled on a new key: Scopus Citation Overview,
  Scopus Author Feedback, ScienceDirect Full-Text Entitlement, ScienceDirect Article Hosting
  Permissions, ScienceDirect Holdings Report, Embase, Engineering Village, SUSHI COP5.

## SDKs

- [elsapy (Python)](https://pypi.org/project/elsapy/) — version 0.5.1, published 2022-11-09.
  First-party, but Elsevier's own support page says "this SDK is not supported by Elsevier",
  and its GitHub repository is archived. There is no JavaScript, Java, .NET, Ruby, PHP, Go or
  Rust client from Elsevier.
